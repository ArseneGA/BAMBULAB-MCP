# Recensement des catalogues officiels Bambu utiles à Printalk

Date : 2026-11-10. Livrable de B3 : on propose, on n'implémente rien d'autre que le catalogue des filaments (`docs/CATALOGUE-FILAMENTS.md`). Règle commune : données embarquées, aucun appel réseau au runtime, aucune IA ; chaque entrée garde source, date et niveau de confiance.

Constat de base, vérifié sur l'installation de Bambu Studio 02.09.00.74 (`resources/`) : Bambu y livre déjà, hors ligne, la plupart de ces catalogues sous forme de profils JSON : `profiles/BBL.json` (15 modèles de machines), `profiles/BBL/machine` (172 fichiers : machines et variantes de buse), `profiles/BBL/filament` (2 092 presets, dont `filaments_color_codes.json`), `profiles/BBL/process` (294), `printers/*.json` (21 fiches de capacités par modèle), `info/nozzle_*.json`, `info/filament_info.json`, `flush/*`. Le wiki, la boutique et MakerWorld n'ont pas pu être téléchargés automatiquement le 2026-11-10 (HTTP 402/403) : ce qui les concerne est marqué « à vérifier ».

Licence : Bambu Studio est publié sous AGPL-3.0 ; ses profils sont des données de configuration. Reprendre des **faits** (noms, valeurs numériques, hex) dans un fichier embarqué avec la source est le niveau d'usage retenu pour le catalogue des filaments ; ne pas recopier les textes de description ni les images (`*_cover.png`, `printers/*.png`). Pour toute reprise à grande échelle, relire `LICENSE.txt` livré avec Bambu Studio (à vérifier juridiquement, hors périmètre technique).

## 3. Limites de ce recensement

Basé sur l'installation locale de Bambu Studio 02.09.00.74 et sur le code du dépôt au 2026-11-10 ; wiki, boutique, MakerWorld non lus en direct (blocage HTTP 402/403) : toute affirmation les concernant est « à vérifier ». Le sens des tableaux `filament_dev_ams_drying_*` (8 valeurs de température, 4 de contrainte AMS) n'est pas documenté dans les profils.
